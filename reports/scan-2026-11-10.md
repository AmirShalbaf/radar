## چطور بخوانی

| ستون | معنا |
|---|---|
| امتیاز | مرکب −۲ تا +۲. ساختار ۴۰٪، قدرت نسبی ۳۰٪، مومنتوم ۱۵٪، جریان ۱۵٪ |
| قدرت نسبی | بازده ۳۰ روزه کوین منهای بازده ۳۰ روزه بیت‌کوین. مثبت یعنی مستقل قوی است |
| فاندینگ داغ | بالای ۰.۰۳٪ یعنی ازدحام لانگ ← ریسک شست‌وشو |
| فشار شورت | بهره باز بالا + فاندینگ منفی ← سوخت صعود |
| جمعیت مقابل نهنگ | بالای ۱.۵ یعنی خرده‌فروش لانگ‌تر از پول هوشمند است |
| **ق.ن ۷ر** | قدرت نسبی ۷ روزه. اگر ۳۰ روزه مثبت و ۷ روزه منفی بود = فرسایش |
| **امتیاز شورت** | ۰ تا ۲، مستقل از امتیاز لانگ. ضعف تازه + لانگ اهرمی نشسته |
| اشباع فروش — پرهیز | RSI زیر ۳۰. سوخت ریزش تمام شده، ریسک جهش |
| نقطه کنترل (POC) | قیمتی که بیشترین حجم آنجا معامله شده — قوی‌ترین سطح |
| ناحیه ارزش | بازه‌ای که ۷۰٪ حجم در آن رخ داده. زیرش = کنترل فروشنده |
| روز | طول پنجره پروفایل حجم به روز. زیر ۱۵ = کم‌اعتبار |
| قدرت‌متوقف | ۳۰ روزه مثبت ولی ۷ روزه در باند ±۱٪ — نه رشد نه افت |
| ناحیه ارزش در جدول شورت | درصد زیر مرز پایین. ۱.۵ تا ۸ درصد = ناحیه ایده‌آل شورت |

> **امتیاز بالا مجوز ورود نیست.** فقط می‌گوید کدام کوین ارزش تحلیل کامل رادار را دارد.
