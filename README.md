# رادار ۵.۳ — ابزار واکشی داده

خروجی یک فایل مارک‌داون است که در گفت‌وگو با کلاود می‌چسبانی.

## فایل‌ها

| فایل | کار |
|---|---|
| `radar_scan.py` | اسکن چند کوین، رتبه‌بندی لانگ و شورت |
| `radar_fetch3.py` | تحلیل عمیق یک کوین |
| `radar_colab.ipynb` | اجرا از موبایل، بدون نصب |
| `requirements.txt` | کتابخانه‌ها |

## اجرا

```bash
pip install -r requirements.txt

# اسکن
python radar_scan.py --preset all --venues okx,gate

# تحلیل عمیق
python radar_fetch3.py XLM --balance 800 --profile trade --venues okx,gate --macro-event 2026-07-29
```

## صرافی‌ها — واقعیت جغرافیایی

| محیط | در دسترس |
|---|---|
| گوگل کولب (سرور آمریکا) | `okx,gate` — بایننس ۴۵۱، بای‌بیت ۴۰۳ |
| لپ‌تاپ + وی‌پی‌ان غیرآمریکایی | `binance,okx,gate,bybit` |
| لپ‌تاپ بدون وی‌پی‌ان از ایران | `okx,gate` |

`okx,gate` پوشش کامل ۵ از ۵ می‌دهد. گیت تنها منبع رایگان تفکیک نهنگ و خرده‌فروش است.

## کلیدها — همه اختیاری

```bash
export COINGECKO_API_KEY=...   # سقف نرخ از ۱۵ به ۳۰ درخواست در دقیقه
export COINGLASS_API_KEY=...   # لیکوئیدیشن
```

ماکرو از CSV فدرال‌رزرو سنت‌لوئیس می‌آید و **کلید نمی‌خواهد**.

⚠️ کلید را داخل کد ننویس — مخزن عمومی است.
