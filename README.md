# رادار ۵.۲ — واکشی داده، نسخه ۳

چند-صرافی + ماکرو رسمی فدرال‌رزرو. خروجی یک فایل مارک‌داون است که در گفت‌وگو با کلاود می‌چسبانی.

## اجرا

```bash
pip install -r requirements.txt
python radar_fetch3.py ONDO --balance 800 --venues binance,okx,bybit,gate
```

| سوییچ | کار |
|---|---|
| `--venues` | ترتیب تلاش صرافی‌ها. هر کدام خطا داد رد می‌شود و بقیه ادامه می‌دهند |
| `--balance` | موجودی دلاری برای محاسبه حجم با ریسک ۲٪ |
| `--profile` | `trade` یا `position` |
| `--macro-event` | تاریخ رویداد ماکرو برای لنگر ج پروفایل حجم |
| `--deep` | تا ۱۰۰۰ کندل روزانه |
| `--stdout` | چاپ در ترمینال بدون ساخت فایل |

## چهار صرافی

| صرافی | کندل | فاندینگ | بهره باز | تفکیک نهنگ |
|---|---|---|---|---|
| بایننس | ✅ | ✅ | ✅ | ✅ **کامل** |
| گیت | ✅ | ✅ | ✅ | ✅ |
| OKX | ✅ | ✅ | ✅ | ❌ فقط کل |
| بای‌بیت | ✅ | ✅ | ✅ | ❌ فقط کل |

کندل فقط از **یک** صرافی گرفته می‌شود (اولین سالم) تا سطوح قیمتی ناهم‌خوان نشوند.
فاندینگ و بهره باز از **همه** صرافی‌ها جمع می‌شود و اگر علامتشان یکسان نبود هشدار می‌دهد.

## ماکرو — بدون کلید

از فدرال‌رزرو سنت‌لوئیس، مسیر CSV که کلید نمی‌خواهد:

| سنجه مشتق | فرمول |
|---|---|
| فاصله سیاست از خنثی | بازده ۲ ساله − سقف نرخ بهره |
| شیب منحنی ۳۰ منهای ۲ | بازده ۳۰ ساله − بازده ۲ ساله |
| بازده واقعی ۱۰ ساله | بازده ۱۰ ساله − نرخ سربه‌سر تورم |
| نقدینگی خالص | دارایی فدرال‌رزرو ÷ ۱۰۰۰ − ریپوی معکوس − حساب خزانه‌داری |
| آزمون ترکیب اشتغال | نرخ بیکاری کنار نرخ مشارکت |

## سه راستی‌آزمایی — حل شد

| # | مسئله | راه‌حل |
|---|---|---|
| ۱ | واحد بهره باز | دو مسیر مستقل، اختلاف بیش از ۲٪ ← تست رد |
| ۲ | ترتیب کندل | مرتب‌سازی صعودی + تست تازگی آخرین کندل |
| ۳ | بازه فاندینگ | از پاسخ خود صرافی، سپس نرمال‌سازی به ۸ ساعت |
